# 🔐 MERN Auth App (Signup + Login)

A full-stack authentication system built using MERN stack (MongoDB, Express, React, Node.js).

---

## 🚀 Features

- User Signup
- User Login
- Password hashing (bcrypt)
- JWT Authentication
- Cookies-based auth (in progress)
- MongoDB Atlas connection
- CORS handling

---

## 🛠 Tech Stack

Frontend:
- React (Vite)
- Axios

Backend:
- Node.js
- Express.js
- MongoDB (Mongoose)
